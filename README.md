# app.ruralconsulting.co.nz

The built web app for Rural Consulting's farm platform, served by GitHub Pages at
https://app.ruralconsulting.co.nz.

This repository holds **only the built site files** (the same files every visitor's browser downloads). It is
published automatically from the private `farm-platform` repository on every merge to `main`; don't edit it by
hand. No client data and no secrets are ever here: farm data stays in the platform's database behind sign-in.
