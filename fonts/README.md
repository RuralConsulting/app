# Paddock fonts

Self-hosted variable WOFF2 assets, no font CDN or runtime package dependency.
Source Sans 3 is the UI family; Source Serif 4 is for farm names and summary sentences.
Latin plus Latin Extended subsets cover Māori macrons (Āā Ēē Īī Ōō Ūū).
Normal variable weights 200–900; browsers may synthesise italic text.

Upstream: https://github.com/adobe-fonts/source-sans and https://github.com/adobe-fonts/source-serif.
These byte-for-byte Fontsource distributions were obtained from the versions below; no local modifications.
Both families use SIL OFL 1.1; the upstream Adobe notices and the distributor's licences are included.
